# ICN app ad

A 25-second vertical ad (1080×1920, 30 fps) for Reels, TikTok, YouTube Shorts and Facebook.

## Videos

| File | Sound |
|---|---|
| `video/ICN-app-ad-1080x1920-voiceover.mp4` | Music and female voiceover (the main version) |
| `video/ICN-app-ad-1080x1920-music.mp4` | Music only |
| `video/ICN-app-ad-1080x1920.mp4` | Silent |

## Script

| Time | On screen | Voiceover |
|---|---|---|
| 0–4 s | A cluttered news portal is struck through: "Stop reading *boring* news portals." | "Still reading boring news portals?" |
| 4–10 s | Phone with the Home feed, swiping through ICN stories: "Just scroll." / "Be cool. Stay *informed*." | "Just scroll." / "Be cool. Stay informed." |
| 10–16 s | Chautari list, then a live room: "Introducing Chautari" / "Listen. Speak. Be *heard*." | "Introducing Chautari. Live audio rooms, on the news." / "Listen. Speak. Be heard." |
| 16–21 s | Open a room, go live, the Earn on Chautari card: "Host a room." / "*Earn* on Chautari." | "Host your own room, and earn on Chautari." |
| 21–25 s | ICN logo draws itself: "For Nepal, from *Nepali*." / नेपालका लागि, नेपालीबाट / ICN.NEWS | "I. C. N. For Nepal, from Nepali." |

The Chautari screens are drawn in the app's style with made-up room names and counts, not recordings of real rooms. The Earn programme is not open yet in the app, so check the wording before running the ad widely.

## How it was made

Everything is generated by the Swift scripts in `src/` on a Mac (Xcode command line tools; no other dependencies):

- `render.swift` draws every frame with CoreGraphics, using the app's own fonts (Newsreader, Archivo, Mukta) and colours from `src/theme/tokens.ts`, and writes the silent H.264 MP4.
- `synth.swift` synthesises the soundtrack from scratch (120 BPM, A minor / C major, no samples), scored to the scene timings. It is original, so it is free to use anywhere.
- `vomix.swift` places the voiceover lines and ducks the music under them.
- `mux.swift` puts the audio into the video without re-encoding it.

The story photos in `img/` are hero images from four icn.news articles published in early November 2026.

### Rebuild

```bash
cd marketing/ad
mkdir -p build/fonts && cp ../../node_modules/@expo-google-fonts/{newsreader/400Regular/Newsreader_400Regular,newsreader/500Medium/Newsreader_500Medium,newsreader/400Regular_Italic/Newsreader_400Regular_Italic,newsreader/500Medium_Italic/Newsreader_500Medium_Italic,archivo/400Regular/Archivo_400Regular,archivo/500Medium/Archivo_500Medium,archivo/600SemiBold/Archivo_600SemiBold,archivo/700Bold/Archivo_700Bold,mukta/500Medium/Mukta_500Medium}.ttf build/fonts/
cp -R img build/img
for s in render synth vomix mux; do swiftc -O -o build/$s src/$s.swift; done
build/render build build/ad.mp4                  # silent video
build/synth build/music.wav                      # soundtrack
mkdir -p build/vo                                # voiceover lines (macOS "say")
say -v Samantha -r 178 -o build/vo/l1.aiff "Still reading boring news portals?"
#   ... l2 to l9: see the cue list in src/vomix.swift; convert each with
#   afconvert -f WAVE -d LEI16@44100 -c 1 lN.aiff lN.wav
build/vomix build/music.wav build/vo build/mix.wav
afconvert -f m4af -d aac -b 256000 build/mix.wav build/mix.m4a
build/mux build/ad.mp4 build/mix.m4a build/ICN-app-ad-1080x1920-voiceover.mp4
```

`render` also takes a third argument, a comma-separated list of seconds, to write PNG stills instead of the video (for example `build/render build build/stills 2,9,20`).

The voiceover uses Samantha, the built-in macOS voice. A Premium voice (System Settings → Accessibility → Spoken Content → Manage Voices) or a recorded voice artist will sound more natural: record the same lines and run `vomix` and `mux` again.

This folder is listed in `.easignore`, so it is never uploaded with app builds.
